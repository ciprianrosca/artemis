# profile/ (gitignored)

Your data lives here, written by `artemis setup` or copied from `examples/demo/` by `artemis demo`:

- `master_cv.md`: your fact bank, the only source for anything Artemis writes about you
- `knowledge.json`: what you're looking for, your filters, constraints and watchlist
- `contact.json`: the contact line printed on resumes
- `comp.local.json`: current pay, floor and target (optional)
- `cvs/`: CVs you've edited and approved, which Artemis uses as the style baseline (optional)

Everything here except this README is gitignored.
